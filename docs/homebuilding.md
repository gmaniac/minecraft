# HomeBuilding

35 building materials plus 8 ready-made houses.

## Materials
Each material is a full block you craft from a representative ingredient (x4 → 4 blocks)
and build with freely.

| Category | Blocks | Crafted from |
|---|---|---|
| planks | Ashwood Planks, Walnut Planks, Pine Planks, Ebony Planks | oak planks |
| beam | Ashwood Beam, Walnut Beam, Pine Beam, Ebony Beam | stripped oak log |
| stone | Smooth Slate, Marble, Bluestone | stone |
| tile | Granite Tile, Ceramic Tile | oak planks |
| brick | Sandstone Brick, Red Brick, Grey Brick, Clay Brick | brick |
| plaster | White Plaster, Grey Plaster, Charcoal Plaster, Tan Plaster | clay ball |
| glass | Clear Glass, Tinted Glass, Frosted Glass | glass |
| shingle | Red Shingle, Grey Shingle, Wood Shingle, Slate Shingle | brick |
| siding | White Siding, Blue Siding, Cedar Siding | oak planks |
| floor | Hardwood Floor, Parquet | oak planks |
| trim | White Trim, Oak Trim | stick |

## Prefab houses
Each house is a **placer item**. Craft it, then **use it** and confirm the prompt — a
complete structure is placed in front of you, oriented to your facing, and built from the
pack's own materials. Big builds place over a couple of seconds.

> Heads-up: placing overwrites whatever blocks are there, so use it on clear ground.

Available houses:
- **Modern House**
- **Cozy Cottage**
- **Cabin**
- **Mansion**
- **Tower**
- **Barn**
- **Shop**
- **Starter Base**
